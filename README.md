## 🧩 Problem-Solving Approach

For many problems, I try to follow this process:

```text
Understand the Problem
        ↓
Find the Pattern
        ↓
Brute Force
        ↓
Optimize
        ↓
Analyze Complexity
        ↓
Implement
        ↓
Test
```

I focus on understanding **why** a solution works rather than simply memorizing it.
